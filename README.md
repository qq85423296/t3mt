# T3MT - 云盘转存管理工具（社区版）
📌 项目简介
T3MT 是一款轻量化网盘转存管理工具，主打夸克网盘、天翼云盘批量转存，内置影视解析、定时任务、多账号管理等实用功能，依托Docker一键部署，适合个人网盘资源收纳、影视资源抓取使用。
⚠️ 重要公告：项目停止维护
本仓库社区版 v3.0.7 为最终冻结版本，现已全面停止维护，不再新增功能、长期Bug不再修复。所有开发迭代、全新功能均迁移至新项目 T3FAP。
新项目地址：https://github.com/qq85423296/T3FAP
✨ 核心功能
- ✅ 夸克网盘、天翼云盘一键转存
- ✅ 全网影视解析、资源下载
- ✅ 批量任务、定时任务自动化管理
- ✅ 多网盘账号统一管理
- ✅ 内置插件系统，支持功能扩展
v3.0.7 最终版本优化点
- 影视解析第三方资源自由开关
- 天翼云下载卡顿自动检测、重试
- 优化任务执行逻辑，完善报错机制
📦 Docker 快速部署（仅旧版留存部署方式）
该部署方式仅适用于停止维护的社区版，推荐直接迁移新项目T3FAP
