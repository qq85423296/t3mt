# T3MT - 云盘转存管理工具（社区版）

> ⚠️ **版本说明**：这是T3MT的社区版本，版本冻结在 v3.0.7。
> 
> 新功能开发已迁移到私有仓库，但Docker镜像会持续更新。

## 📦 快速开始

### 使用Docker部署（推荐）

```bash
# 拉取最新镜像
docker pull 85423296/t3mt:latest

# 下载配置文件
wget https://raw.githubusercontent.com/qq85423296/t3mt/main/docker-compose.yml

# 启动服务
docker-compose up -d

# 访问
http://localhost:8520
```

## ✨ 功能特性

### 核心功能
- ✅ 夸克网盘转存
- ✅ 天翼云盘转存

- ✅ 批量任务管理
- ✅ 定时任务调度
- ✅ 多账号管理

## 🐳 Docker镜像

所有版本的Docker镜像统一发布到Docker Hub：

```bash
# 最新稳定版
docker pull 85423296/t3mt:latest

# 指定版本
docker pull 85423296/t3mt:3.0.7

# 测试版
docker pull 85423296/t3mt:test
```

**镜像说明**：
- `latest`: 最新稳定版（包含专业版功能）
- `3.0.7`: 社区版最终版本
- `test`: 测试版（包含最新开发功能）

## 🔧 从源码构建

社区版支持从源码构建：

```bash
# 克隆仓库
git clone https://github.com/qq85423296/t3mt.git
cd t3mt

# 构建镜像
docker build -t t3mt:community .

# 运行
docker-compose up -d
```
